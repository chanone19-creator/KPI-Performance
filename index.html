เชื่อมกับ Google Sheets
ข้อมูลบันทึกใน Google Sheets ของคุณเอง
ทำครั้งเดียว 5 นาที → ใช้งานได้ตลอด บนเครื่องไหนก็ได้
1
เปิด Google Sheets → สร้าง Spreadsheet ใหม่ → ตั้งชื่อว่า KPI System
2
ใน Spreadsheet → เมนู Extensions → Apps Script
3
ลบ Code เดิมทั้งหมด แล้ว วาง Code จากไฟล์ apps-script.js ที่ดาวน์โหลดมา → กด Save
4
กด Deploy → New deployment → Type: Web app
→ Execute as: Me → Who has access: Anyone → Deploy
5
คัดลอก Web app URL (ขึ้นต้นด้วย https://script.google.com/macros/s/...) วางด้านล่าง
วาง Web App URL แล้วกดเชื่อมต่อ
URL จะเก็บในเครื่องนี้เท่านั้น
